# `capacity` command group

## `list` command
List all capacities in the Fabric tenant.

By default, output is written to `stdout` in tabular format. The `--output json` option overrides this behavior.

```sh
fabutil capacity list
```
List capacities to `stdout` in tabular format.

```sh
fabutil capacity list --output json
```
List capacities to `stdout` as a JSON array.
